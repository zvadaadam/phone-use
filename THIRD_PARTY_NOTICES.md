# Third-party notices

Phone Use currently ships no third-party runtime library. The macOS app and CLI
use Apple system frameworks; the dashboard uses browser platform APIs.

Research consulted open-source device tooling and automation projects, including
pymobiledevice3, but no source from those projects is copied into the product.
Their repositories retain their own licenses.

Development-only npm dependencies remain subject to the licenses recorded in
package-lock.json.
